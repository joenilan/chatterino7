# Channel header

Chatterino's split header behaviour, matching how the owner uses it:

- **Middle-click the channel name** (`# channel`) to open `twitch.tv/<channel>` in the
  browser. Dragging the name still moves the pane.
- **Hover the channel name** for a card: a live thumbnail (Twitch's preview image,
  refreshed every 5 minutes, preloaded for visible live channels), title,
  category, viewers and uptime. When offline it says so. Ctrl+I opens full details.
- In your own channel, the ✎ button edits the title and category.

Evidence (Windows, 2026-10-11): hovering #thewisegrape showed the live thumbnail, title,
"Rocket League · 263 viewers" and "Live for 15h 30m". An offline channel showed
"Offline". Middle-click opening the browser has not been tried in the real app yet.
