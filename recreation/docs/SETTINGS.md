# Settings window

The titlebar gear opens Settings directly. It is a centred window that fades and rises in over 180 ms
(instant with reduced motion). Sections are listed on the left, and the left list collapses to icons on narrow windows. Esc, the close button, or a click
outside closes it. Esc leaves it open while an editor opened from it is on top.

Every row has the same shape: title, one-line explanation, and the control on the right (switch,
segmented choice, or a button that opens an editor).

| Section | Contents |
|---|---|
| General | Layout (Viewer/Moderator/Streamer), Studio panel (Streamer), live-only tabs, live-only workspaces, Twitch accounts, Import from Chatterino, discard-and-quit (only after a failed save) |
| Appearance | Text size, timestamps, pause scrolling, chatter nicknames & colours |
| Chat | Chat memory, load recent messages, custom commands, ignores |
| Highlights | Highlight words, highlight rules, event highlights |
| Notifications | Live alerts for every channel, whispers |
| Connections | Share 7TV activity, Streamer.bot (live status text + Set up) |
| Shortcuts | Keyboard and mouse shortcuts |
| Updates | Version and check, automatic checks |

Workspace actions moved out of the old gear menu to a right-click menu on each workspace in the
sidebar: Rename, Move up/down, Only show live workspaces, Reopen closed workspace, Close
workspace…. Switch channel, channel search, highlights and mark-all-read keep their shortcuts and
are listed under Shortcuts. Whispers and highlights also have their own titlebar buttons.

Evidence (Windows, 2026-10-11): opened from the gear, and all pages render; Esc closes it. The sidebar right-click menu shows
with Move down disabled on the last workspace.
